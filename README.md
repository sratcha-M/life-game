# 🌱 เส้นทางชีวิต (Life · Path)

เกม Visual Novel ที่ให้ผู้เล่นใช้ชีวิตตั้งแต่แรกเกิดจนถึงวันเกิดปีที่ 70 ทุกทางเลือกกำหนดว่าคุณจะเติบโตเป็นใคร มีอาชีพอะไร รักใคร และชีวิตจะจบลงแบบไหน
เล่นบนเว็บได้ทั้งมือถือและคอมพิวเตอร์ ไม่ต้อง login ก็เล่นได้

---

## 🎮 วิธีเล่น

1. **สร้างตัวละคร** ตั้งชื่อ แล้วเลือกเพศ
2. **เปิดไพ่ดวงชะตา** เลือก 1 จาก 3 ใบ (มี 15 แบบ เช่น 🧠 หัวไวตั้งแต่เกิด, 💰 เกิดในบ้านรวย, 🏚️ บ้านยากจน, 🤒 ร่างกายอ่อนแอ)
3. **เลือกความฝันของชีวิต** เป้าหมายที่อยากทำให้ได้ก่อนอายุ 70 (มี 10 แบบ เช่น 💎 เศรษฐีสิบล้าน, 🏡 ครอบครัวอบอุ่น, 🏆 สุดยอดในอาชีพ)
4. **ใช้ชีวิต** แตะเพื่ออ่านบทพูด แล้วเลือกทางเลือกในแต่ละช่วงวัย บางฉากเป็นการ์ดให้ปัดซ้าย/ขวา/ขึ้นแบบ Reigns บางฉากมีจับเวลา บางฉากเป็นมินิเกม
5. **ฉากจบ** สรุปชีวิตทั้งหมด พร้อมเหตุผลที่ได้ฉากจบนี้ ทางที่ไม่ได้เลือก และสมุดชีวิต

## 📊 ค่าสถานะ

| ค่า | ความหมาย |
|---|---|
| 📘 ความรู้ | การเรียน ปลดล็อกอาชีพสายวิชาการ (แพทย์ วิศวะ ทนาย นักบิน) |
| 💪 ร่างกาย | สุขภาพ กีฬา ตำรวจ อายุยืน |
| 🎨 ศิลปะ | นักวาด นักดนตรี นักแสดง |
| 🗣️ เข้าสังคม | เพื่อน ความรัก ครีเอเตอร์ |
| 😊 ความสุข | สภาพจิตใจ มีผลต่อฉากจบและการออกบวช |
| 💰 เงิน | ฐานะการเงิน |

นอกจากนี้ยังมี **ระบบการเงินจริง** (เงินสด / เงินลงทุน / หนี้ หน่วยเป็นบาท) คิดเงินเดือน รายจ่าย ดอกเบี้ย ผลตอบแทนการลงทุน และเหตุการณ์ไม่คาดคิด (โดนเลิกจ้าง โบนัส ป่วย ฯลฯ) ตามสถิติจริงของแต่ละช่วงอายุ

## 🧭 ช่วงชีวิต

วัยทารก → วัยเด็ก → วัยรุ่น → วัยหนุ่มสาว (อายุ 22 เลือกอาชีพ) → วัยทำงาน → วัยเกษียณ

เกมมีทั้งหมด **441 ฉาก** ได้แก่ เรื่องหลัก เหตุการณ์สุ่ม ความสัมพันธ์กับครอบครัวและเพื่อน (แม่ พ่อ ยาย น้อง ต้น ฟ้า เจ โกโก้) งานเฉพาะอาชีพ ความลับ กรรมที่ตามมา และเรื่องแปลกเหนือธรรมชาติ

## 💼 อาชีพ (23 อาชีพ)

| สายวิชาชีพ | สายสร้างสรรค์ | สายอิสระ / อื่น ๆ |

แต่ละอาชีพมีเงื่อนไขปลดล็อก (เช่น ต้องเรียนแพทย์ หรือต้องมีความรู้ 7+) และมีฉากเฉพาะของอาชีพนั้น 2 ฉาก
อาชีพอิสระ (เกษตรกร นักบวช ไรเดอร์ สตรีมเมอร์ ขายของออนไลน์) **ไม่มีหัวหน้า** จึงไม่เจอฉากเจ้านาย/HR/เลื่อนขั้น/เลิกจ้าง

## 🏁 ฉากจบ (19 แบบ)

- **ฉากจบดี (7):** 🏆 ตำนานแห่งวงการ · 🏡 บ้านที่อบอุ่นที่สุด · 🤝 เพื่อนตายตลอดชีวิต · 🌈 ชีวิตที่เลือกเอง · 🌾 กลับสู่รากเหง้า · 🎂 ร้อยปียังแจ๋ว · ☀️ ชีวิตธรรมดาที่ไม่ธรรมดา
- **ฉากจบแย่ (8):** 💎 เศรษฐีผู้เดียวดาย · 🌧️ ถ้าย้อนเวลากลับไปได้ · 🕯️ จากไปไวเกินไป · ⛓️ ชีวิตหลังลูกกรง · 🏃 ผู้หลบหนี · 📉 หนี้ท่วมหัว · 🥀 งานคือชีวิต · 🩺 ร่างกายที่ไม่ได้ดูแล
- **ฉากจบแปลก (4):** 👽 ไปเที่ยวดาวอื่น · 🐈 ชาตินี้ขอเป็นแมว · 👻 เพื่อนเก่าใต้ถุนบ้าน · 👶 เกิดใหม่อีกครั้ง

## ✨ ระบบเด่น

- **บุคลิกชีวิต** เกมวิเคราะห์จากทางเลือกตลอดชีวิตว่าคุณเป็นคนแบบไหน (ฉลาด กล้า เปราะบาง เมตตา ฯลฯ) และบทพูดบางฉากจะเปลี่ยนตามบุคลิก
- **ธงชีวิต / กรรม** ทางเลือกตอนเด็กส่งผลย้อนกลับมาตอนโต เช่น ช่วยเพื่อนตอนโดนแกล้ง แล้วเพื่อนจะไม่มีวันลืม
- **มินิเกม 5 แบบ:** 🏃 วิ่งแข่งกีฬาสี (แตะรัว) · ✏️ สอบเข้า ม.1 (คิดเลข) · 🧺 เก็บเงินพาร์ทไทม์ (รับเหรียญ) · 🃏 เกมจับคู่ · 💓 จังหวะหัวใจ
- **โหมดหาเงิน (Hustle)** ช่วงที่ต้องปั่นเงินให้ถึงเป้าภายในเวลาที่กำหนด
- **ชาติที่ 2 (โหมดยากที่สุด)** เกิดใหม่พร้อมกรรมจากชาติก่อน ห้ามเลือกทางเดิม ต้องได้ฉากจบใหม่และความฝันใหม่
- **ส่งต่อตระกูล** ถ้ามีลูก เล่นต่อเป็นลูกรุ่นถัดไปได้ พร้อมมรดก (หรือหนี้) และของตกทอดตามอาชีพพ่อแม่
- **ปลดล็อก 11 อย่าง** เช่น ไพ่ใบที่ 4, สับไพ่ใหม่, ไพ่พิเศษ (🪷 วิญญาณเก่า, 👑 ทายาทตระกูลดัง, 👽 ฝุ่นดาว) และความฝันพิเศษ
- **อัลบั้มชีวิตและของสะสม** เก็บทุกชีวิตที่เคยเล่น ฉากจบที่เคยได้ ถ้วยรางวัล และความลับ
- **เสียง** มีเพลงประกอบ เสียงเอฟเฟกต์ และเสียงพากย์ (ไฟล์ mp3 + Web Speech API)
- **แชร์ผลชีวิต** สรุปชีวิตเป็นข้อความสำหรับวางในแชต

## ☁️ บัญชีและเซฟบนคลาวด์

ไม่ login ก็เล่นได้ ข้อมูลจะเก็บไว้ในเครื่อง (localStorage)
ถ้าสมัครหรือ login ด้วยอีเมล เกมจะซิงก์เซฟ อัลบั้มชีวิต ฉากจบ ถ้วยรางวัล และความลับขึ้น **Firebase (Auth + Firestore)** ให้เล่นต่อได้ทุกเครื่อง
แต่ละคนอ่าน/เขียนได้เฉพาะข้อมูลของตัวเอง (ดูกฎใน [firestore.rules](firestore.rules) และวิธีตั้งค่าใน [FIREBASE_SETUP.md](FIREBASE_SETUP.md))

## 🛠️ สำหรับนักพัฒนา

**เทคโนโลยี:** React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · Firebase · Playwright (เทสต์อัตโนมัติ)

```bash
npm install
npm run dev          # เปิดเซิร์ฟเวอร์พัฒนา
npm run build        # build ไปที่ dist/
npm run preview      # ดูผล build
npm run deploy       # build + deploy ขึ้น Firebase Hosting พร้อม Firestore rules
npm run sim          # จำลองการเล่นหลายรอบเพื่อตรวจสมดุลเกม
SINGLE=1 npm run build   # build เป็นไฟล์ HTML ไฟล์เดียว ไว้ส่งให้ลองเล่น
node scripts/playtest.mjs <โฟลเดอร์> [mobile]   # เล่นอัตโนมัติจนจบพร้อมถ่ายภาพหน้าจอ
```

### โครงสร้างโปรเจกต์

```
src/

  game/
    engine.ts        เลือกฉากถัดไป ค่าสถานะ ฉากจบ
    story.ts         เนื้อเรื่องหลักตามช่วงวัย
    events.ts, life.ts, drama.ts, cards.ts, later.ts …   เหตุการณ์ย่อย การ์ด และเรื่องต่อเนื่อง
    jobs.ts, careers.ts   ฉากเฉพาะอาชีพ และข้อมูลอาชีพ/เงินเดือน
    finance.ts, realstats.ts   ระบบการเงินและสถิติจริง
    goals.ts         ไพ่ดวงชะตา ความฝัน ถ้วยรางวัล
    karma.ts, secrets.ts, threads.ts, bonds.ts   กรรม ความลับ ความสัมพันธ์
    persona.ts, personaHooks.ts   วิเคราะห์บุคลิกและบทพูดตามบุคลิก
    meta.ts          ของปลดล็อก มรดก การส่งต่อรุ่น
  components/        MiniGame, HustleMode, SwipeChoice, Account (login)
  art/               ฉากหลังและตัวละคร
  lib/               cloud.ts (Firebase), sound.ts, voice.ts, emoji.ts
  assets/            ภาพฉากหลัง ตัวละคร อีโมจิ 3 มิติ และเสียงพากย์
```

### หมายเหตุเรื่อง responsive
- ขนาดทุกอย่างใช้หน่วย `rem` และขนาดฐานใน [src/index.css](src/index.css) ปรับตามขนาดจอ (16px บนมือถือ ถึงประมาณ 21px บน Full HD) แก้ตัวเลขบรรทัดเดียวก็มีผลทั้งเกม
- `vite.config.ts` ตั้ง `build.cssTarget` ให้แปลง CSS ของ Tailwind 4 เป็นแบบที่ iPhone/Android รุ่นเก่าและเบราว์เซอร์ในแอป LINE/Facebook อ่านได้
